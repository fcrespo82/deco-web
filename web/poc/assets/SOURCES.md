# Fotografias oficiais usadas localmente na POC

Baixadas em 2026-11-16. Convertidas de JPEG para PNG sem mudar enquadramento ou coordenadas. Direitos das imagens pertencem à TP-Link; os PNGs ficam fora do Git, como as imagens Deco já existentes no projeto.

- `tl-sg108-ports.png`: https://static.tp-link.com/upload/image-line/TL-SG108_UN_5.0_02_normal_20231024111419p.jpg
- `deco-x50-ports.png`: https://static.tp-link.com/upload/image-line/Deco_X50_Overview_02_normal_20211224063508o.jpg

Ambas têm 590 × 590 pixels. As portas foram identificadas visualmente; `photo-geometry.js` guarda os pontos no sistema de coordenadas da imagem. São imagens demonstrativas de modelos específicos, sem afirmar que todos os dispositivos reais sejam desses modelos.
